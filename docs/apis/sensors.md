# Sensors (SensorThings API)

BGS provides a selection of sensor data using the OGC [SensorThings API](https://www.ogc.org/standards/sensorthings/) standard. Documentation and examples are on the dedicated site: <https://sensors.bgs.ac.uk/>.

For other sensor data offerings and downloads see [BGS sensor data](https://www.bgs.ac.uk/technologies/sensor-data/).
