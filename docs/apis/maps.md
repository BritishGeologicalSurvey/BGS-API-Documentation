# Maps (WMS)

The BGS Maps API serves pre-rendered map images in two projections: British National Grid for GB data and Web Mercator for global use. Maps are requested with the OGC [Web Map Service](https://www.ogc.org/standards/wms/) (WMS) standard, which is supported by most GIS software.

See [BGS web map services](https://www.bgs.ac.uk/technologies/web-map-services-wms/) for the full list of services.
