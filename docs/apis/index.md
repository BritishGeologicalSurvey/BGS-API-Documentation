# APIs

BGS publishes a selection of open data through standards-based web APIs, for developers, data scientists, academics and GIS users who want to work with the data programmatically or keep a live connection to frequently updated datasets.

| Service | Standard | Base URL |
| --- | --- | --- |
| [Features](features.md) | OGC API – Features (with CQL2 filtering) | <https://ogcapi.bgs.ac.uk/> |
| [Maps](maps.md) | OGC Web Map Service (WMS) | see [WMS services](https://www.bgs.ac.uk/technologies/web-map-services-wms/) |
| [Sensors](sensors.md) | OGC SensorThings API | <https://sensors.bgs.ac.uk/> |

We'd welcome [feedback or suggestions](https://github.com/BritishGeologicalSurvey/BGS-API-Documentation/issues), including what other data would benefit from API delivery.
